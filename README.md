# 🦆 [FinQuack](https://tio-patinhas-ai.lovable.app/) - Seu Mentor de Finanças Pessoais.
> Clique no link acima para acessar o app.

### Resumo do [App](https://tio-patinhas-ai.lovable.app/)
* O FinQuack é um assistente financeiro com Inteligência Artificial que ajuda pessoas a organizar suas finanças por meio de conversas simples e naturais.

* Com o apoio do Tio Patinhas$$, o usuário pode registrar receitas e despesas, acompanhar metas, visualizar relatórios, receber insights personalizados e aprender sobre educação financeira sem depender de planilhas ou sistemas complexos.

* Mais do que um aplicativo financeiro, o FinQuack foi criado para ser um mentor financeiro digital disponível 24 horas por dia, tornando a organização financeira mais simples, acessível e motivadora.

FINQUACK APP

Crie uma aplicação SaaS moderna chamada FinQuack, uma plataforma de organização financeira baseada em Inteligência Artificial.

O FinQuack deve funcionar como um assistente financeiro conversacional que ajuda usuários a controlar gastos, organizar receitas, acompanhar metas financeiras, aprender educação financeira e tirar dúvidas sobre investimentos.

O principal diferencial do produto é um assistente virtual chamado Tio Patinhas$$.

Toda a experiência da aplicação deve ser construída ao redor dele.

O usuário não deve sentir que está usando uma planilha financeira ou um sistema de gestão tradicional.

O usuário deve sentir que possui um mentor financeiro pessoal disponível 24 horas por dia.

O Tio Patinhas$$ deve ser o centro da experiência.

PROBLEMA QUE O PRODUTO RESOLVE
--------------------------------------------------------------------------------

Muitas pessoas desistem de cuidar das próprias finanças porque:

- Aplicativos financeiros exigem preenchimento manual.
- Interfaces são complexas.
- Há pouca personalização.
- O usuário não recebe orientação financeira constante.
- O processo é desmotivador.

O FinQuack resolve esse problema utilizando uma experiência baseada em conversação.

Exemplos de mensagens:

"Gastei R$ 45 no almoço."

"Recebi R$ 4.000 de salário."

"Quanto gastei com alimentação neste mês?"

"Quanto falta para atingir minha meta?"

"O que é Tesouro Selic?"

"Qual a diferença entre CDB e CDI?"

CONCEITO CENTRAL

O usuário deve conseguir realizar ações sem precisar navegar por múltiplas telas ou preencher formulários complexos.

A IA deve interpretar a intenção da mensagem e agir automaticamente.

--------------------------------------------------------------------------------

1. Registro de despesas por linguagem natural.

Exemplos:

- Paguei R$ 50 de Uber.

- Valor
- Data
- Categoria
- Descrição
- Tipo da transação

Registrar sem exigir entrada manual adicional.

2. Registro de receitas e despesas.

--------------------------------------------------

4. Dashboard financeiro.

- Saldo atual

- Total de despesas
- Economia mensal
- Principais gastos
- Evolução financeira

6. Relatórios financeiros.

- Evolução das metas

DESIGN UNIVERSAL E ACESSIBILIDADE
--------------------------------------------------------------------------------

O FinQuack deve seguir os princípios de Design Universal para garantir que qualquer pessoa consiga utilizar a aplicação de forma simples, intuitiva e inclusiva.

O produto deve ser projetado para atender usuários com diferentes níveis de conhecimento tecnológico, capacidades cognitivas e necessidades de acessibilidade.

Princípios obrigatórios:

1. Uso simples e intuitivo

- A interface deve ser compreendida sem necessidade de treinamento prévio.
- A navegação deve ser natural e previsível.
- O usuário deve compreender facilmente o que fazer em cada tela.

2. Linguagem clara

- Evitar termos técnicos sem explicação.
- Utilizar português simples e acessível.
- Explicar conceitos financeiros utilizando exemplos do cotidiano.

3. Baixa carga cognitiva

- Evitar excesso de informações simultâneas.
- Priorizar uma tarefa principal por tela.
- Utilizar hierarquia visual clara.
- Reduzir distrações desnecessárias.

4. Acessibilidade visual

- Contraste elevado entre textos e fundos.
- Seguir padrões WCAG AA ou superiores.
- Não depender exclusivamente de cores para transmitir informações.
- Ícones sempre acompanhados por texto.

5. Tipografia acessível

- Fonte altamente legível.
- Tamanho mínimo de texto de 16px.
- Espaçamento confortável.
- Suporte para aumento de fonte sem quebrar layouts.

6. Interação inclusiva

- Botões com área mínima de toque de 44x44px.
- Compatibilidade total com dispositivos móveis.
- Interações fáceis mesmo para usuários idosos.

7. Compatibilidade com leitores de tela

- Uso adequado de labels.
- Componentes acessíveis por teclado.
- Estrutura semântica correta.
- Compatibilidade com tecnologias assistivas.

8. Feedback constante

Todo evento deve apresentar feedback claro.

Exemplos:

- Receita registrada com sucesso.
- Despesa adicionada.
- Meta criada.
- Informação salva.

O usuário nunca deve ficar sem saber se uma ação foi concluída.

9. Prevenção de erros

- Confirmações antes de exclusões.
- Sugestões automáticas.
- Validações amigáveis.
- Recuperação simples de erros.

10. Design emocional

O produto deve transmitir:

- Segurança
- Confiança
- Clareza
- Progresso
- Motivação

O usuário deve sentir que está sendo guiado por um mentor financeiro confiável.

11. Dark Mode

Implementar suporte completo a:

- Light Mode
- Dark Mode

Respeitando preferências do sistema operacional.

12. Microinterações acessíveis

Utilizar animações suaves para:

- Criação de metas
- Registro de transações
- Conquistas financeiras
- Atualizações de progresso

Evitar animações excessivas ou que prejudiquem acessibilidade.

13. Navegação orientada

O produto deve guiar continuamente o usuário.

Sempre que possível, o Tio Patinhas$$ deve sugerir próximos passos relevantes.

Exemplos:

- Criar uma meta financeira.
- Revisar gastos do mês.
- Aprender um conceito financeiro.
- Organizar despesas recorrentes.

14. Inclusão financeira

O produto deve ser útil para:

- Pessoas sem experiência financeira.
- Pessoas endividadas.
- Pessoas que estão começando a investir.
- Jovens adultos.
- Adultos maduros.
- Idosos.

15. Experiência Conversacional Acessível

O chat deve ser projetado para ser a forma mais fácil de interação.

O usuário deve poder:

- Registrar transações.
- Consultar relatórios.
- Criar metas.
- Tirar dúvidas.
- Aprender sobre investimentos.

Tudo utilizando linguagem natural sem necessidade de menus complexos.

 O produto deve estar preparado para futuras integrações com Open Finance.

Não implementar inicialmente:

- Integrações bancárias
- Compra de investimentos
- Venda de investimentos
- Consultoria financeira regulada
- Planejamento tributário avançado
- Marketplace financeiro
- Cartão de crédito próprio

OBJETIVO FINAL
--------------------------------------------------------------------------------

Entregue um MVP funcional e visualmente impressionante do FinQuack.

O produto deve combinar organização financeira, educação financeira, acompanhamento de metas e inteligência artificial conversacional.

O diferencial principal é o relacionamento contínuo entre o usuário e o assistente Tio Patinhas$$.

Todo o sistema deve ser projetado para que o usuário sinta que possui um mentor financeiro digital acompanhando sua evolução financeira diariamente.

REQUISITO CRÍTICO

O FinQuack deve ser desenvolvido seguindo os princípios de Design Universal, WCAG 2.2 AA e Mobile First.

O sistema deve ser utilizável por usuários iniciantes, idosos, pessoas com baixa alfabetização digital e usuários com necessidades de acessibilidade.

Toda decisão de UX deve priorizar simplicidade, inclusão, clareza e facilidade de uso.
